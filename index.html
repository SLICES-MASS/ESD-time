How the estimate is built

For planning only. The estimate is an expected average for similar procedures. Bleeding, unexpected fibrosis and other intraprocedural events can lengthen individual procedures.

Model: log-linear regression of procedure time (capped at 180 min), full cohort n = 9,771. Predicted time = exp(LP) × 1.180 (Duan smearing factor). LP = 2.2394 + 0.2752·log₂(size) + grade [2: 0.1380, 3: 0.4005, 4: 0.6730, 5: 0.8214] + flat 0.0848 / depressed 0.1184 + differentiated 0.2104 / undifferentiated 0.2738 / other 0.1184 + scar 0.6057 + suspected SM 0.1536 − 0.0634·experience + endoscopist sedation 0.1058 + male 0.0960 − 0.0023·age. Location difficulty grade: 1, antrum GC/AW/PW; 2, antrum LC; 3, angle, lower body, middle body LC/AW/PW; 4, upper body LC/PW; 5, middle body GC, upper body AW/GC, cardia/fundus. Validation (2021–2026, n = 3,645): R² 0.37, mean absolute error 13.9 min, AUC 0.85 / 0.91 / 0.90 for ≥60 / ≥90 / ≥120 min.
